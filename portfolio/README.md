# Jeswanth Surya Portfolio
Run: `npm install && npm run dev` then open http://localhost:3000
Shortcuts: T tour, A agents, P pause. `?agents=on` forces the animation, `?agents=off` disables it.
Content lives in `lib/data.ts`. Set `SHOW_PHONE = true` there only if you want your number public.
Deploy: push to GitHub, import at vercel.com/new, click Deploy.
